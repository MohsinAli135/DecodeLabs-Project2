# DecodeLabs - Project 2: Responsive Web Layout

A responsive, mobile-first web layout built with modern HTML5, CSS Grid, Flexbox, and JavaScript. This project focuses on modern web layout standards, dynamic scaling, and clean structural architecture.

## Project Overview

This web layout was built as part of the DecodeLabs Web Development Internship program. The primary goal was to create a clean, responsive user interface that adapts seamlessly across mobile, tablet, and desktop viewports without relying on heavy external frameworks.

## Key Features

- **Mobile-First Layout:** Designed primarily for mobile screens and progressively enhanced for larger viewports using CSS media queries.
- **Grid & Flexbox:** Built using CSS Grid for the overall page structure and Flexbox for internal card alignment.
- **Fluid Scaling:** Typography and spacing scale dynamically across screen sizes using CSS `clamp()` functions.
- **Accessibility:** Touch targets and buttons meet minimum target size guidelines for accurate interaction on touch devices.

## Tech Stack

- **HTML5:** Semantic HTML structure.
- **CSS3:** Native CSS Grid, Flexbox, dynamic variables, and media queries (`768px`, `1024px+`).
- **JavaScript:** Client-side scripting for menu toggles and interactive elements.
